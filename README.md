# Sticker Space · 开源核心版

GPL-3.0-only。浏览器里的曲面贴纸编辑器，React + Three.js + Vite。

## 运行

需要 Node.js 24、pnpm 10.34.6：

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm test
```

默认使用程序生成的电线杆。附带 3 张独立生成的简单 PNG，支持导入自己的 PNG、GLB、GLTF、USDZ。保留曲面贴合、贴纸编辑与撕除、撤销恢复、本地工程、手机触控、旋转/倾斜/漂浮、背景及 USDZ/视频导出代码。

## 与正式网站的区别

未分发授权待确认的案例模型、原贴纸包、商业站点字体、品牌图、头像、私人测试文件、MP3、照片猫爪。替代图形仅为程序绘制的占位素材。大卫与路牌字体是有单独许可证的示例资源；见 THIRD_PARTY.md。

手机/iPad MP4 在浏览器本地编码；USDZ 也本地生成。iOS 实况依赖用户自行安装 Actions App 并配置快捷指令，链接仅为便利，不表示可用性保证。安卓实况未验证兼容，界面隐藏实况和 USDZ 入口。4K60 导出文件可能因播放设备而不够流畅。

macOS 原生导出助手保留 Swift 源码（native-helper/Sources），但不附带签名 App、安装包、FFmpeg 可执行文件。桌面透明视频等依赖该助手的功能需要自行构建并提供 FFmpeg。网页下载助手的商业站点安装包链接在本发行版禁用。旧的 ffmpeg.wasm 透明视频备用代码保留，但未打包其 GPL 核心，默认不启用。普通 MP4 和 USDZ 不依赖它。

工程资源默认存在本地浏览器 IndexedDB。请用“保存工程”备份；生产网站与本地开发不共用草稿。没有服务器账户、上传服务或必需密钥。
