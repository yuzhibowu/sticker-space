# David — Michelangelo

3D scan: **Scan the World @ MyMiniFactory.com** / Jonathan Beck.
Original: https://commons.wikimedia.org/wiki/File:David_(Michelangelo).stl
Artwork / Scan the World: https://www.myminifactory.com/object/3d-print-michelangelo-s-david-in-florence-italy-2052
License: **CC BY-SA 4.0**, https://creativecommons.org/licenses/by-sa/4.0/

`david.mesh.gz` is an adaptation under the same CC BY-SA 4.0 license.
Changes: converted from STL, changed from Z-up to Y-up, centered, scaled to 5.4 scene units, reduced triangle count with a 0.04% relative geometric error limit, generated smooth normals and physical box-projected stone UVs (chart boundaries split to avoid stretching along limbs), quantized positions to 0.00001 scene units, packed normals/UVs, compressed binary mesh. The original source remains linked above. The adapted geometry is publicly downloadable from `/models/david.mesh.gz`.

This is a full-body Scan the World scan of Michelangelo's David. The Google Arts & Culture page also presents a Scan the World David; this app uses the openly licensed full-body file above, rather than claiming to extract Google's viewer asset.
