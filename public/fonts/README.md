# Sticker Lab Sign Sans outlines

Derived from Noto Sans CJK SC Bold. © 2014-2021 Adobe (http://www.adobe.com/).

Licensed under the SIL Open Font License 1.1; complete license: ../licenses/NotoSansCJK-OFL.txt.

Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese

The asset contains 28,314 glyph outlines for Chinese, Latin letters and common punctuation. Outlines are quantized to 1,000 units, contour direction is reversed for Three.Font, and the resulting JSON is gzip compressed. The original font name is retained only as attribution; the derived outline family is named Sticker Lab Sign Sans.

Rebuild: `node scripts/build-sign-font.mjs /path/to/NotoSansCJKsc-Bold.otf` from the repository root.
